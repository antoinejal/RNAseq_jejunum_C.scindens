# Bulk RNAseq C. scindens, Jejunum

## File Descriptions

Below, you can find descriptions of the files found under **scripts/**. The files were ran in the oredered in which they are described. 

| File | Description |
|---|---|
| `01_RNA_seq_processing.R` | Sample processing: quality control ufing FastQC, reference genome uploading and indexing followed by STR alignment. Creation of a RNAseq object for downstrem analyses. |
| `PCA.R` | Principal Component Analysis. |
| `02_DEA.R` | Differentially expressed gene analysis between the different conditions (CD, HFD, and HFD CS). |
| `03_GSEA.R` | Gene set enrichment analysis between the different conditions (CD, HFD, and HFD CS), based on the results obtained from `02_DEA.R`. |
| `04_ORA.R` | Over representation analysis between different comparisons, based on the results obtained from `02_DEA.R`. For example, HFD_CS__vs__CD_PBS__vs__HFD_PBS__vs__CD_PBS. |
| `exploration.R` | Creation of various plots: DEA volcano plots, summary barplots, upset plots, and logFC correlation plots, GSEA dotplots, and selected genes analyses. |
| `05_exploration.R` | Antoine's plotting script exploring: ORA plots, GSEA heatmaps. Most plots use genes that Alessia and Antoine have selected specifically. If you do not find some selection dataframes ask them. |
| `plot_replications.R` | Reproduction of certain plots (GSEA Up/Down dotplots and GSEA heatmaps) from `05_exploration.R` with a different contrast: HFD CS vs. CD, instead of HFD vs. CD. |
